# BAISERKE JEM — редактирование сайта

## Основные файлы

- `packages/web/src/web/lib/products.ts` — все 21 товара, цены, фасовки, фотографии и описания на трёх языках. `price: null` означает «Уточнить цену», а не нулевую стоимость.
- `packages/web/src/web/lib/i18n.ts` — переводы интерфейса: русский, казахский, английский.
- `packages/web/src/web/lib/store.tsx` — корзина, сохранение языка/темы и формирование сообщения WhatsApp.
- `packages/web/src/web/components/shop-layout.tsx` — общая шапка, футер и компонент `Brand`, где сейчас находится текстовая заглушка будущего логотипа.
- `packages/web/src/web/pages/` — главная, каталог, товарные страницы, информационные страницы, корзина и подтверждение.
- `packages/web/public/images/` — локальные фотографии. Новые фото и логотип следует помещать сюда и ссылаться на них через `/images/имя-файла`.

## Работа заказа

Корзина, язык и тема сохраняются в localStorage. Контактные данные клиента не записываются в хранилище сайта. После оформления открывается WhatsApp на номер +7 777 823 33 71 с готовым сообщением. Клиент должен нажать «Отправить» в WhatsApp самостоятельно. Сайт не проверяет, отправил ли клиент сообщение.

Черновик сообщения подтверждения хранится только в памяти текущей вкладки. После обновления страницы необходимо повторно заполнить форму; товары сохраняются в корзине.

Известные цены суммируются отдельно. Товары «Уточнить цену» и доставка не входят в эту сумму. Для комбикорма мешок 25 кг рассчитан как 175 × 25 = 4 375 ₸, мешок 40 кг — 7 000 ₸. Все шесть вариантов муки приведены в исходных ценах. Гречка — только по запросу из-за расхождения в материалах.

## Перед публикацией

- Подтвердите цены, наличие, варианты рыбы и точку самовывоза. Карта использует координаты старого сайта.
- Загрузите новый логотип: старый логотип не использовался в шапке и футере.
- Добавьте настоящие отзывы с разрешения клиентов. Сейчас раздел честно сообщает, что подтверждённых отзывов в материалах нет.
- Показатель 200+ тонн в месяц обозначен как архивный. Замените его только на подтверждённые актуальные данные.
- Фотографии частично извлечены по ссылкам старого сайта, частично взяты как иллюстративные. Перед публичным использованием проверьте права и по возможности замените снимками своей продукции. Некоторые товары используют общие иллюстрации, а не фотографии конкретного вида.

## Техническая проверка

`bun run dev` — запуск сайта на закреплённом порту. `bun run build` — сборка и TypeScript. `bun run lint` — проверка проекта. База данных, авторизация, платежи и дополнительные API для сайта не используются.
